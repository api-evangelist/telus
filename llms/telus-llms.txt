# TELUS

> TELUS Corporation is one of Canada's three national facilities-based telecommunications carriers, operating a nationwide mobile network alongside broadband, TV, security, health (TELUS Health) and agriculture businesses. TELUS publishes no llms.txt of its own; this file is generated by API Evangelist from the apis.yml catalog entry and the artifacts harvested into the api-evangelist/telus repository on 2026-07-25.

TELUS is partner-gated. Its branded API Marketplace at api.telus.com is a login wall, developers.telus.com resets anonymous connections, and its CAMARA network APIs (Number Verification, SIM Swap) reach developers only through EnStream LP -> Aduna -> CPaaS partners such as Vonage. Exactly two TELUS APIs are documented publicly, and neither is self-serve:

1. TELUS Insights Location API — de-identified, aggregated mobile-network geo-intelligence for Canada. REST, asynchronous job queue, OAuth 2.0 client credentials plus a customerId header. 27 documented operations. Reference published through Postman Documenter; credentials issued by sales-led onboarding.
2. TELUS Health CHR Enterprise API — the Collaborative Health Record ambulatory-care platform, exposed as GraphQL. 505 types, 64 root queries, 49 mutations, plus a 21-topic signed webhook service. Self-signed RS512 JWT authentication; a paid feature enabled per CHR account.

Neither API publishes an OpenAPI document. There is no MCP server, no CLI, no client SDK in any language, no status page, and no idempotency contract on either surface.

## APIs

- [TELUS Insights Location API](https://docs.insights.telus.com/): Asynchronous geo-intelligence counts — demographic, unique devices, origin, destination, OD matrix, dwell time, total trip, repeat visitation, trade area, home and work — computed over shapefile study zones. Base URL https://location-api.insights.telus.com/product/insightsRequest/v1
- [TELUS Health CHR Enterprise API](https://help.inputhealth.com/en/collections/3317215-chr-enterprise-api): GraphQL access to CHR patients, appointments, encounters, referrals, cases, tasks, group visits, lab results and health profiles.
